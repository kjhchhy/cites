PROJECT PLAN

CITES 생물·서류·거래처 관리 서비스

소규모 전문 샵 운영자가 개체와 증빙 기록을 한곳에서 관리하도록 돕는 웹 서비스 기획서

1. 프로젝트 목적

CITES 대상 생물을 사육·관리하는 개인이 개체 정보, 사진, 번식 기록, 관련 서류와 중요한 일정을 한곳에서 확인하고 관리할 수 있게 한다.

흩어진 파일과 개인 기억에 의존하던 업무를 정리해, 개체의 이력과 증빙 사진을 빠르게 찾고 신고에 필요한 기록을 놓치지 않게 하는 것이 목표다.

2. 대상 사용자

주 사용자: CITES 대상 생물을 사육·번식하는 개인

파충류 등을 사육하며 개체의 출생·번식 기록과 증빙 사진, 관련 서류를 직접 관리한다. 현재는 휴대전화 사진첩, 컴퓨터 폴더, 메신저, 종이 서류철에 자료가 나뉘어 있다. 사업자용 기능은 이후 단계에서 검토한다.

사용 상황

  • 특정 개체의 출생·번식 이력과 증빙 사진을 바로 확인해야 할 때
  • 산란·부화가 발생한 뒤 날짜, 부화 온도, 사진을 기록할 때
  • 증식신고 등에 필요한 개체·번식 기록을 모아 점검할 때
  • 양도한 개체와 연결된 자료의 보관 상태를 정리할 때

3. 사용자가 겪는 문제

  • 개체 사진과 서류가 여러 장소에 흩어져 있어, 필요한 순간에 빠르게 찾기 어렵다.
  • 산란일·부화일·부화 온도 같은 번식 기록을 기억이나 메모에 의존해 누락하기 쉽다.
  • 증식신고에 필요한 사진과 기록을 한 번에 모으기 어렵다.
  • 양도한 개체의 자료를 언제 지워도 되는지, 여러 개체가 연결된 서류는 어떻게 관리해야 하는지 혼란스럽다.
  • 고용량 사진이 쌓이며 저장 공간이 부족해질 수 있다.

4. 해결 방법

사용자 불편서비스 해결 방식
사진·서류를 찾기 어렵다개체마다 관련 서류와 사진을 연결해 한 화면에서 조회한다.
번식 기록이 누락된다산란일, 부화일, 부화 온도와 관련 사진을 개체 또는 번식 기록에 남긴다.
신고 자료를 모으기 어렵다개체별 이력과 증빙 사진을 날짜순으로 관리해 필요한 기록을 빠르게 검토한다.
양도 뒤 자료 정리가 어렵다양도 상태와 연결 개체 수를 확인하고, 서류의 모든 연결 개체가 양도된 뒤 1개월 후 삭제 후보로 표시한다.
사진 저장 공간이 부족하다사진 업로드 때 용량을 줄이는 기능을 제공하고, 보관 공간 사용량을 보여 준다.

6. 핵심 사용자 흐름

회원가입·로그인→ 개체 등록→ 사진·서류 연결→ 번식 기록 등록→ 내부 알림 확인
  1. 사용자는 새 개체의 종명, 식별번호, 입고일, 보유 상태를 입력하고 생물 종류 카테고리를 선택한다.
  2. 개체 사진과 필요한 서류를 첨부한다. 사진은 필요할 때 용량을 줄여 업로드한다.
  3. 산란·부화가 발생하면 날짜, 부화 온도와 관련 사진을 번식 기록에 추가한다.
  4. 대시보드에서 확인이 필요한 내부 알림과 양도 후 삭제 후보 자료를 점검한다.
  5. 신고 또는 기록 확인 시 개체 화면에서 이력, 사진, 연결 서류를 바로 확인한다.

8. 디자인 분위기

  • 신뢰감 있고 차분한 개인 관리 도구: 과도하게 장식하기보다 정보의 상태와 다음 할 일을 명확히 보여 준다.
  • 자연 친화적이되 전문적인 색감: 짙은 녹색, 옅은 민트, 흰색을 중심으로 생물 관리의 성격과 문서 관리의 신뢰감을 함께 표현한다.
  • 한눈에 파악되는 화면: 상태 배지, 만료 임박 표시, 표와 카드로 정보를 빠르게 훑을 수 있게 한다.
  • 비개발자·소규모 사업자 친화성: 전문 용어에는 짧은 설명을 붙이고, 복잡한 입력을 단계별로 나눈다.

9. 개발 전 확인 질문

  1. 관리 생물 범위: 초기 버전은 CITES 대상 생물 전반을 관리한다. 관리 방식은 공통으로 두되, 생물 종류별 카테고리로 분류한다.
  2. 기록 범위: 정해진 서류 종류를 필수로 제한하지 않는다. 개체·산란·부화·사육장 시설 사진과 번식 정보를 선택적으로 기록한다.
  3. 사진과 서류 보관: 사진은 용량 축소 기능을 제공한다. 연결된 모든 개체가 양도되어 서류 수량이 소진된 뒤 1개월이 지나면 해당 서류와 사진을 삭제 후보로 안내한다.
  4. 알림 방식: 첫 버전에서는 서비스 내부 알림만 제공한다.
  5. 계정·권한: 첫 버전은 개인용 단일 계정으로 시작한다. 사업자용 다중 계정과 권한은 이후 검토한다.
  6. 자료 가져오기: 기존 엑셀·폴더 자료 가져오기는 첫 버전에 포함하지 않는다.
  7. 법률·행정 고지: 서비스가 법률·행정 자문이나 신고의 정확성을 보증하지 않으며, 최신 기준은 관계 기관에 확인해야 한다는 고지를 제공한다.
