CITES 애완동물
개인 브리더 관리 서비스

개체·서류·사진·증식 기록을 안전하고 쉽게 정리하는 개인용 관리 도구

1. 프로젝트 목적

개인 브리더가 사육하는 CITES 대상 애완동물의 개체 정보, 관련 서류, 사진과 증식 기록을 한곳에서 관리하도록 돕는 웹 서비스다.

휴대전화 사진첩, 컴퓨터 폴더, 종이 서류철에 흩어진 기록을 개체별로 연결해, 필요한 사진과 이력을 빠르게 찾고 증식신고에 참고할 정보를 놓치지 않게 한다.

2. 대상 사용자

주 사용자: CITES 대상 애완동물을 사육·번식하는 개인 브리더

파충류 등 CITES 대상 생물을 사육하며 개체의 출생·보유·양도 이력, 관련 증빙과 번식 사진을 직접 기록하는 사람이다. 직원·거래처 관리가 필요한 사업자용 기능은 첫 버전의 범위에서 제외한다.

대표적인 사용 상황

  • 특정 개체의 출생·보유 이력과 관련 사진을 바로 확인할 때
  • 산란·부화 후 날짜, 부화 온도, 증빙 사진을 기록할 때
  • 증식신고를 준비하며 필요한 개체·번식 기록을 모을 때
  • 개체 양도 후, 관련 자료의 보관 상태를 정리할 때

3. 사용자가 겪는 문제

  • 개체 사진과 서류가 사진첩·메일·폴더·종이 서류철에 흩어져 필요할 때 찾기 어렵다.
  • 산란일, 부화일, 부화 온도 같은 번식 정보를 메모나 기억에 의존해 누락하기 쉽다.
  • 증식신고에 참고할 사진과 기록을 한 번에 모으려면 여러 곳을 다시 확인해야 한다.
  • 양도한 개체의 자료를 언제 정리할지, 여러 개체가 연결된 서류를 어떻게 보관할지 헷갈린다.
  • 고용량 사진이 계속 쌓여 저장 공간이 부족해질 수 있다.

4. 해결 방법

사용자 불편첫 버전의 해결 방식
자료가 흩어져 있다개체별 페이지에 사진, 서류, 번식 기록을 연결해 한곳에서 조회한다.
번식 기록을 놓친다산란일, 부화일, 부화 온도, 알 수·부화 수와 관련 사진을 선택적으로 기록한다.
사진 용량이 부담된다업로드 시 사진 용량 축소 기능과 저장 공간 사용량 안내를 제공한다.
양도 후 자료 정리가 어렵다연결된 모든 개체가 양도된 뒤 1개월이 지난 서류·사진을 삭제 후보로 안내한다. 실제 삭제는 사용자가 확인한다.
중요한 일을 잊는다첫 버전에서는 서비스 내부 알림으로 확인이 필요한 기록과 삭제 후보를 알려 준다.

6. 사용자 흐름

개체 등록→ 사진·서류 연결→ 증식 기록 추가→ 내부 알림 확인
  1. 사용자는 종명, 식별 정보, 입고·출생일, 보유 상태를 입력하고 생물 종류 카테고리를 선택한다.
  2. 개체 사진 또는 관련 서류를 첨부한다. 필요하면 사진 용량을 줄여 저장한다.
  3. 산란·부화가 발생하면 날짜, 부화 온도와 관련 사진을 번식 기록으로 추가한다.
  4. 대시보드에서 내부 알림과 삭제 후보 자료를 확인한다.
  5. 신고 준비 또는 기록 확인 때 개체 상세 화면에서 이력·사진·서류를 함께 본다.

8. 디자인 분위기

  • 신뢰감 있는 개인 관리 도구: 장식보다 기록 상태와 다음 행동을 명확히 보여 준다.
  • 자연 친화적이면서 전문적인 분위기: 짙은 녹색, 옅은 민트, 흰색을 중심으로 생물 관리와 문서 기록의 성격을 함께 표현한다.
  • 사진 중심의 정보 구성: 개체·산란·부화 사진을 날짜와 상태가 보이는 카드로 쉽게 확인한다.
  • 비개발자 친화성: 전문 용어에 짧은 설명을 붙이고, 입력 흐름은 작은 단계로 나눈다.

9. 개발 전 확인 질문

  1. 첫 버전에서 지원할 생물 종류 카테고리는 어떻게 나눌 것인가?
  2. 개체를 식별하는 핵심 정보는 무엇이며, 필수·선택 항목을 어떻게 구분할 것인가?
  3. 사진 파일의 최대 용량, 지원 형식, 자동 압축 품질은 어느 수준으로 정할 것인가?
  4. 서류·사진은 실제 자동 삭제가 아니라 삭제 후보 안내와 사용자 확인으로 시작할 것인가?
  5. 증식 기록에서 산란일·부화일·부화 온도 외에 첫 버전부터 필요한 항목은 무엇인가?
  6. 데이터를 클라우드에 저장할 때 백업 방식과 개인정보·사진 접근 보호는 어떻게 할 것인가?
  7. 서비스가 법률·행정 자문이나 신고의 정확성을 보증하지 않으며, 최신 기준은 관계 기관에 확인해야 한다는 고지를 어디에 표시할 것인가?
