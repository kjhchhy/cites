프론트엔드

사용자가 웹사이트나 앱에서 직접 보고, 읽고, 누르는 화면 부분을 말합니다.

쉬운 비유

프론트엔드는 카페의 매장 앞 공간과 메뉴판과 같습니다. 손님이 보는 간판, 메뉴, 주문 버튼, 좌석처럼 사용자가 서비스를 이용할 때 직접 만나는 부분입니다.

초보자용 예시

온라인 쇼핑몰에서 상품 사진, 가격, “장바구니에 담기” 버튼을 보는 것이 프론트엔드입니다. HTML로 내용과 구조를 만들고, CSS로 보기 좋게 꾸미고, JavaScript로 버튼을 눌렀을 때 화면이 바뀌도록 만듭니다.

수업에서 기억할 점

프론트엔드는 사용자 눈앞의 화면입니다. 반대로 로그인 정보나 주문 내역을 서버에서 처리하고 저장하는 보이지 않는 부분은 보통 백엔드라고 합니다.
