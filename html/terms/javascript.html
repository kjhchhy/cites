JavaScript

웹페이지가 사용자의 행동에 반응하고 움직이도록 만드는 프로그래밍 언어입니다.

쉬운 비유

JavaScript는 집 안의 전기와 자동 장치와 같습니다. 스위치를 누르면 불이 켜지고, 초인종을 누르면 소리가 나듯 버튼을 누르면 화면에 변화가 생기게 합니다.

초보자용 예시

온라인 쇼핑몰에서 “장바구니에 담기” 버튼을 눌렀을 때를 떠올려 보세요. JavaScript가 없다면 버튼은 화면에 보이기만 합니다. JavaScript는 버튼을 눌렀다는 사실을 알아차리고, 장바구니 숫자를 0에서 1로 바꾸고 “상품을 담았습니다”라는 안내를 화면에 보여 줍니다.

즉, HTML이 버튼을 만들고 CSS가 버튼을 예쁘게 꾸민다면, JavaScript는 버튼을 눌렀을 때 무엇을 할지 정합니다.

수업에서 기억할 점

JavaScript는 페이지의 동작과 상호작용을 담당합니다. HTML은 구조, CSS는 꾸밈, JavaScript는 사용자의 행동에 반응하는 움직임이라고 구분하면 쉽습니다.
