HTML과 index.html

웹사이트를 처음 만날 때 가장 자주 보게 되는 두 이름입니다. 둘 다 웹페이지를 만드는 데 쓰이지만, 역할은 조금 달라요.

HTML이란?

HTML은 웹페이지에 무엇이 놓일지 정하는 문서 형식입니다. 제목, 문단, 사진, 버튼, 링크 같은 내용을 컴퓨터에게 알려줍니다.

쉽게 비유하면: HTML은 집의 뼈대와 방 배치도예요. “여기는 현관”, “여기는 침실”처럼 웹페이지의 기본 구조를 정합니다.
카페 홈페이지라면
HTML은 “카페 이름”, “오늘의 메뉴”, “주문하기 버튼”, “매장 사진”이 어디에 있어야 하는지를 담습니다. 글씨 색이나 예쁜 꾸밈은 보통 CSS, 버튼을 눌렀을 때의 동작은 JavaScript가 맡습니다.

HTML 파일 이름은 대개 .html로 끝납니다. 예를 들어 about.html은 ‘소개’ 페이지가 될 수 있어요.

index.html은 무엇인가요?

index.html은 특별한 문법이 아니라 관례적으로 쓰는 파일 이름입니다. 많은 웹 서버는 주소에서 파일 이름을 생략하면, 해당 폴더의 index.html을 먼저 보여 주도록 설정되어 있습니다.

도서관 비유
index.html은 도서관 입구의 안내 데스크와 비슷합니다. 방문자가 어느 자료를 찾을지 아직 정하지 않았을 때 가장 먼저 만나는 안내 페이지예요.
예시:
example.com/에 접속 → 서버가 index.html을 보여 줌
example.com/about.html에 접속 → about.html을 보여 줌

한눈에 비교

  • HTML: 웹페이지의 구조를 만드는 언어(또는 문서 형식)
  • index.html: 보통 웹사이트나 폴더의 첫 페이지에 붙이는 HTML 파일 이름

즉, index.html은 HTML로 작성된 여러 파일 중 ‘첫 화면’ 역할을 맡는 경우가 많은 파일입니다.
